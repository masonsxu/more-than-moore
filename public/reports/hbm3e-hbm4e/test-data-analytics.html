数据底座：五层管道

测试分析的第一性问题不是算法，而是数据从哪来、按什么标准落地。ATE 产生逐 die 参数记录（STDF）与空间良率图（SEMI E142 XML）， 经特征工程进入模型层，最终落到四个决策动作：接受 / 剔除 / 复测 / 自适应改流，判定结果回流训练。

Fig.02 · Statistical Screening

统计筛查基石：PAT / DPAT / GDBN

在引入任何机器学习之前，产线筛选的主力是基于分布的统计离群剔除：对每个测试项按总体分布设限（PAT）， 按批次动态重算限值（DPAT），在晶圆图上按空间邻域剔除坏区里的好 die（GDBN）。车规体系由 AEC-Q001/Q002 固化为指南。

Fig.03 · Yield Modeling

良率与堆叠建模

良率模型回答「给定缺陷密度 D 与裸片面积 A，良率是多少」。四条经典曲线出自同一复合泊松框架，差别只在缺陷密度的分布假设； 工业界最常用负二项（Stapper）模型，因为它刻画缺陷聚集——纯 Poisson 会低估良率。

堆叠复利：n 层综合良率 = ∏ yᵢ；等良率时 yⁿ（0.95¹⁶ ≈ 44%） KGD 筛选后：0.99¹⁶ ≈ 85% —— 每层良率 +4pp，堆叠良率 +41pp 复合泊松：Murphy=三角密度 · Seeds=指数 · 负二项=Gamma（Cunningham 1990 / Stapper 1987） 良率模型是后面一切测试经济学的分母

Fig.04 · Wafer Map Pattern Recognition

晶圆图失败模式识别：WM-811K 与深度学习

公开数据集 WM-811K 收录 811,457 张真实晶圆图（约 4.6 万批），其中 172,950 张由领域专家标注为 9 类失败模式。 它是晶圆图识别算法的标准基准：在标注子集上，自编码器增广 + CNN 达到 98.56%（Bao et al. 2024）； 类不平衡用 GAN 增广缓解（DCGAN 路线，Park & You 2023）。原引"99%+ 精度 @ 93% 覆盖（Yoon 2022）"与"G2LGAN（Tsai 2025）"未能溯源，已于 2026-09-19 核对时删除。

Fig.05 · Outlier Detection & Adaptive Test

异常检测算法族与自适应测试闭环

单颗 die 的测试项向量构成多维分布，离群检测 = 多维分布的尾部判定。无监督四法（高斯模型 / 单类 SVM / 隔离森林 / 自编码器） 不需要失效标签；自适应测试则更进一步——用模型预测代替部分实测，预测可信则跳项，不可信则判废或加测。

无监督异常检测四法 生产离群检测文献

  • 高斯模型：多维 ±kσ 椭球门限，PAT 的多维推广
  • One-class SVM：学习正常边界，小样本稳健
  • Isolation Forest：随机切分隔离离群点，近线性复杂度
  • Autoencoder：重构误差作离群分数，可并入晶圆图管线
  • 评测用 PR-AUC，不用 accuracy（失效率 1e-6 量级）

测试结果预测 自适应测试核心

  • 双预测器（Pan 2024，合肥工业大学，JETTA）：预测好 → 跳过后续测试项；预测坏 → 直接判废
  • 复测成功预测（Selg 2020，LATS）：判断对单颗 die 追加复测是否值得
  • VMIN 预测（Synopsys，出处待核）：ML 预测最小供电电压 → 自适应设限
  • 老化时间缩减：参数测试分析预测可靠性，缩短 burn-in

虚拟量测 Virtual Metrology

  • GPR 回归（Wan 2017）：设备传感数据 → 预测量测值，带不确定度
  • VM + 动态抽样（Jia 2026）：全量预测 + 按需实测，喂 R2R 控制
  • 产线意义：量测是抽样，VM 补全为逐片预测，抽验预算重新分配
  • 良率学习闭环：VM 数据提前于测试暴露工艺漂移

Fig.06 · 3D / HBM Specific Analytics

3D 堆叠特有：KGSD 分层、逃逸乘法与测试调度

堆叠改变了两件事：测试对象从单 die 变成层级组合（pre-bond KGD → 逐层 post-bond 复测 → KGSD 终测； KGSD 术语见 SK 海力士官方后道工艺系列。原引"Hot Chips，K. Tran：3/5/9 组合"未能溯源，下图已改为通用示意——K. Tran 实为 FormFactor 产品营销负责人）， 以及逃逸被乘法放大——一颗坏 die 逃逸，报废的是整个堆栈。测试访问按 IEEE 1838-2019 逐层打通。

Fig.07 · Test Economics

测试经济学：在哪儿拦截缺陷

测试策略的本质是成本最优：总成本 = 测试成本 + 逃逸率 × 现场失效成本（行业通用测试经济学框架；原引"NXP 框架"未能定位原文）。 三个输入都可测：测试步骤成本、无该步骤的逃逸率、单次现场返修成本——最优拦截点就是总成本曲线的谷底。

现场 DPPM = 逃逸率 × 10⁶ 堆叠逃逸 ≈ n · ε（16 层 × 100 DPPM/die = 1600 DPPM） Yield-to-Quality：在良率与质量间找平衡（SemiEngineering） 拦截位次：越靠前拦截越便宜——KGD 筛选的本质动机

Playbook

落地五步

1 · 数据层

  • STDF / E142 → 列式存储 + 特征仓，die 级主键 = 批 + 坐标

2 · 基线

  • 先跑 AEC-Q001/Q002 统计基线，任何 ML 与 DPAT 基线对比增量

3 · 指标

  • 1e-6 失效率场景用 PR-AUC / 逃逸率 / 误杀率，不用 accuracy

4 · 验证

  • 按批留出回测 + 抽验复核（闭环③），上线前过双盲对比

5 · 运维

  • 漂移监控（SPC）+ 模型版本化，回流数据触发再训练

结论：统计筛查定基线，机器学习挣增量；堆叠场景先算清逃逸乘法，再决定每一层测试的深度。
