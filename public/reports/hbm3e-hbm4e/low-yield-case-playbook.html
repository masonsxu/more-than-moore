01 · Lifecycle

Case 生命周期与阶段门

未达出口判据不进入下一阶段；证伪回到假设清单重排，是循环不是失败。形状承载语义：椭圆起止、矩形步骤、菱形判定，焦橙仅标记证实路径与根因对策。

阶段关键动作出口判据

有效性核查§03 六项检查确认数据真实，才进入产品归因

02 · Trigger & Triage

触发来源与前两小时：先核查数据，再怀疑产品

新手最大的坑是把"测试系统说谎"当成"产品坏了"。警报确认后先做数据有效性六项核查，再做基本盘七问——初报的事实骨架由七问构成，不由猜测构成。

数据有效性核查（六项）

  • datalog 完整性：文件数 vs 机台产出数；解析器报错
  • 程序 / limit 版本：JOB_REV vs MES 工单绑定；limit diff
  • 分母定义：gross/net die、edge exclusion 口径与基线一致
  • 复测记录：retest 标志解析；同 die 多条 PRR 去重规则
  • 机台状态：校准到期、温度实际值、prober 对准零点
  • 报表复算：手工重算一个 lot 良率，排除 YMS 统计 bug

基本盘七问

  • 掉多少：基线 X% → Y%，差 Z pp；影响 N lot / M wafer
  • 何时开始：第一颗异常 wafer 的测试结束时间（END_T），不是发现时间
  • 哪里掉：产品 × 插入点 × 工站逐层定位
  • 是否单点：单 lot / wafer / tester / 针卡 / site——单点性是假设骨架
  • 有何改动：4M 清单（机 / 料 / 法 / 人），回溯 72h
  • 系统是否撒谎：左侧六项
  • 客户影响：已放行？追回？

04 · Method

分析方法：从假设清单到双根因

先 Is / Is-Not 矩阵（KT 法）收窄原因域，再按先验概率 × 验证成本排序假设。任何"A 比 B 差"必须过两比例检验（差值 + 95% CI + n）；多 site / 多 tester 比较做多校正（FDR 或 α/n）。

Is / Is-Not（示例）

  • 什么：bin1 3.9%，bin4 正常 → 接触类
  • 哪里：tester 2 的 site 3/7 → site 相关
  • 何时：08-21 起 → 变更点在前夜
  • 程度：FPY −4.4pp、final −1.2pp → 回收高，接触类

假设优先级 C

  • 针卡磨损 / 污染（先验最高）
  • 接触 / 共面性、程序 limit 变更
  • 机台校准、物料批次
  • 真实工艺异常（排除法最后一档）

双根因（D4 硬要求）

  • 发生根因：为什么坏（针尖磨损 + 清洗周期过长）
  • 流出根因：为什么没拦住（SPC 没监控 TD、site 级无告警）
  • 只答发生根因的 8D 会被 QE 退回
五个常见陷阱：① 先入为主只找支持证据——用 Is/Is-Not 强制对称；② raw bin Pareto 误读 fail-stop 删失；③ 复测回收混入 FPY 掩盖接触类问题；④ n=40 失效就宣称 bin"翻倍"；⑤ 只做统计不做实物——缺 FA 证据链的 case 关不掉。

05 · Report

分析报告：8D 逐节写法

客户 case 必须出正式 8D；内部 case 可简化为异常单但结构相同。初报当天发（事实 + 围堵），终报带 FA 证据。

节内容必含要素常见退回原因
D0征兆响应触发规则、发现时间线缺时间线
D1CFT 团队TE/QE/设备/产品/计划 + Champion单部门闭门造车
D2问题描述5W2H + Is/Is-Not；基线、分母口径、影响面、客户影响良率口径不清
D3临时围堵 ICA覆盖范围、已流出清点与召回、ICA 有效性数据只写"已 hold"不写流出面
D4根因（双）发生 + 流出；每条假设的证实/证伪结果只有发生根因；假设未逐条关闭
D5永久对策对策与根因一一对应；多选一的比较依据对策与根因无对应
D6实施与验证验证实验设计、连续 N lot 数据、SPC 恢复证据无量化有效性
D7预防FMEA 更新、SPC 规则、SOP、培训、横展清单无横展
D8关闭QE 签核；（客户 case）客户书面同意缺客户批准

报告最低配图（5 张）

  • by-lot 良率趋势（标基线带 + 变更点）
  • first-fail bin Pareto（含 n 与 CI）
  • 异常 / 正常 wafer map 对比
  • site / tester 分解
  • 关键相关性图（如 fail 率 vs TD 计数）

判定措辞分级

  • 已证实：统计相关 + 物理 FA + 再现/消除实验，三角闭合
  • 高度可能：统计相关 + 机理，缺再现实验
  • 待验证：仅相关，样本量不足或存在未排除混杂

06 · Verification

验证：证据三角，缺一角关不掉

统计相关

假设因子与失效显著相关：差值 + CI + n；剂量-响应（失效率 ∝ 暴露量，如 TD 计数）是最强形态；警惕针卡与机台绑定的混杂。

物理证据 FA

X-ray（键合空洞 / 对准）、SAT（分层 / 裂纹）、显微 / SEM（针尖磨损形貌）、切片 + EDX（污染成分）。FA 结果必须与电测签名兼容。

再现 / 消除实验

再现：故意用嫌疑因子打良 lot，签名复现；消除：更换因子，良率回基线。C 对策有效性：连续 ≥3 lot FPY 回基线 ±0.5pp、retest 回落、SPC 连续 ≥25 点受控。

07 · Closure

确认与关闭：判据清单

  • 双根因均被证据三角证实；流出根因对应的全部逃逸 lot 已完成围堵处置
  • D6 有效性达标：连续 3 lot / 20 wafer 回基线 ±0.5pp（C）
  • SPC 连续 ≥25 点受控，无新增判异
  • 围堵措施撤除后一个生产周期内无复发
  • D7 完成：FMEA 行更新、SPC / 警报规则导入、SOP 修订、横展清单关闭
  • 知识库归档：case 编号、时间线、数据快照、FA 报告
  • 签核链：TE → QE；客户 case 加客户书面批准
重开条件：监控窗口（惯例 30 / 60 / 90 天，按严重度）内同根因复发 → 立即重开并升级一级。复发说明 D4 / D5 至少一项不成立——禁止"二次围堵了事"。
