# 来源 7：Tom's Hardware — TSMC 与 GUC 披露 HBM4/HBM4E/C-HBM4E 3nm base die

- URL: https://www.tomshardware.com/pc-components/dram/hbm-undergoes-major-architectural-shakeup-as-tsmc-and-guc-detail-hbm4-hbm4e-and-c-hbm4e-3nm-base-dies-to-enable-2-5x-performance-boost-with-speeds-of-up-to-12-8gt-s-by-2027
- 发布背景: TSMC European OIP forum（2025 年 11 月下旬）
- 抓取日期: 2026-09-18（页面正文仅抓到导语，以下为可验证内容）

---

- HBM performance has increased by an order of magnitude since its inception around a decade ago, but many elements remained unchanged between HBM1 and HBM3E.
- At TSMC's European OIP forum, HBM4 and HBM4E will offer four major changes:
  - HBM4: 2,048-bit interface and base dies produced using advanced logic technologies.
  - HBM4E: customizable base dies, controllable with custom interfaces.
- Title-level claims: C-HBM4E 3nm base dies; up to 2.5x performance boost; speeds of up to 12.8 GT/s by 2027.
- Related manufacturing flow description (from search summary): DRAM die fabrication on advanced memory process nodes; base die fabricated separately and increasingly on a logic-oriented process rather than a DRAM-oriented one; TSV formation follows.
