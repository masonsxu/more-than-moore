## 一、你的日常栈 × 笔记里的词

| 你的世界 | 笔记里的词 | 关系 |
|---|---|---|
| **WPFile**（CP 晶圆测试数据文件，厂内/测试机链路） | **STDF**（国际 ATE 通用标准，Teradyne/Advantest 生态） | 同类数据的不同封装。字段语义一一对应：lot / wafer / die / x-y 坐标 / bin / 测试项 / 测量值 / 上下限。解析器换壳，方法论零变化 |
| **MES**（批次、谱系、放行中枢） | 笔记中"MES 谱系" | 同物。lot / wafer / die / 插入点 / 程序版本的主键都从这里来 |
| **EAP**（Equipment Automation Program，设备自动化，走 SECS/GEM） | 笔记中"设备联网 / SECS/GEM（SEMI E5/E30）" | EAP 是 SECS/GEM 在厂内的实现载体；路线图 S0 的"设备联网盘点"就是对 EAP 的接口盘点 |
| **EDA**（Equipment Data Acquisition，SEMI E134 数据采集管理 + E164 公共元数据） | 笔记中"FDC 参数轨迹 / 高频设备数据" | EDA 是高频参数级采集的标准（区别于 EAP 的事件/状态级）。S2 的 FDC 雏形吃的就是 EDA 数据 |
| **广立微 DataExp-YMS** | 笔记中"分析工作台 / 看板 / 统计基线" | DataExp-YMS 官方口径支持 CP、FT、WAT、Inline、Defect、WIP 多类型数据的清洗、整合与良率分析——它是成品软件；路线图自建的部分是与它互补的管道、统计引擎与追溯服务 |
| **广立微 WAT 测试设备**（晶圆级电性参数测试） | 笔记中"过程量测" | 同物，WAT 数据同样进字典化管道 |

**一句话**：STDF 不是唯一真神，它是国际生态最大的通用格式；你厂里的数据走 WPFile + 广立微链路，两者字段语义同构——笔记里所有"STDF 解析器"读作"WPFile/STDF 解析器"，所有方法论（字典化 → 管道 → 统计基线 → 模型）原样成立。

## 四、聚焦建议：学习预算怎么分

三星/海力士/美光的工艺与路线图材料是**行业语境**——作用是看懂客户产品怎么演进（HBM 层数、接口、键合方式变化 → 测试数据量与测试策略怎么变），不是你要实现的东西。

可落地核心是**方法论层**，与具体存储厂无关：

- S0–S2：数据字典化、管道、PAT/DPAT/SPC/GDBN（全部有公开标准与文献支撑）
- 测试经济学（1-10-100）、逃逸算术（0.95¹⁶≈44%）
- 治理设计（IP 分级、品质唯一放行）

**预算分配建议：70% 方法论与厂内栈（WPFile→管道→统计基线），30% 行业语境**。判断一条材料值不值得深学：问"下个月的管道/基线工作用不用得上"——HBM4E 引脚速率是 14 还是 16 Gbps，不影响你写解析器；PAT 限值怎么按 lot 分层，影响。
