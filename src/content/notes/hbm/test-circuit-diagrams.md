不是研发也没关系——每张图都只保留理解数据所需的最少元件，每个元件标注"它存在的理由"。第四节再把六种失效各画一张**模拟电路级**原理图：测量环路怎么搭、缺陷在电路哪个位置、读数怎么超限判 bin。

## 一、设计电路图：这些电路为什么存在

![设计电路图：PMU 测量环路 + 被测电路的设计意图](/diagrams/test-design-circuit.svg)

**左半边（ATE 侧，"问"的电路）四件套：**

1. **DAC + 运放**：设定"施加多大的电压/电流"——刻度由模式决定（FVMI 加压 / FIMV 加流）；
2. **RRANGE 感测电阻**：量程档（±2 μA–±50 mA）。量程越小分辨率越高——所以测 μA 级漏电必须切灵敏档（Marvin Test KB 原文口径）；
3. **钳位（CLAMP HI/LO）**：一物两用——既保护 DUT 不被加坏，又是"开路"的判别上界（FI 模式下电压只能顶到钳位）；
4. **窗口比较器**：读数落在限值窗内吗？硬件直接输出 PASS/FAIL——测试程序只是读这个结果。

**右半边（DUT 侧，"答"的电路）全部是芯片原有设计，测试只是借用：**

- **ESD 保护二极管对**：本职是防静电。接触测试拿它当"已知二极管"——对它加 100 μA 量级电流，好焊盘读出约 0.6–0.7 V 的二极管压降（器件物理教科书量级），开路顶到钳位，对地短路约 0 V；
- **VDD/VSS 电源轨**：PowerShort 测的就是这两条轨之间的阻抗状态；
- **内部电路/DRAM 阵列列**：功能测试（MBiST）的对象——DC 全过之后才轮到它。

机制依据：ADI MAX9979 设计笔记、AD5520/AD5522 手册（每引脚 PMU + 钳位 + 窗口比较器）、Marvin Test KB Q200207；接触测试方法出自 US5365180A。全文摘录归档见 [`public/sources/hbm-test/2026-09-25_ate-pmu-dc-parametric.md`](/sources/hbm-test/2026-09-25_ate-pmu-dc-parametric.md)。

## 二、逻辑图：测试程序怎么一步步判 bin

![逻辑图：测试程序 fail-stop 判定流](/diagrams/test-logic-flow.svg)

看这张图抓三个要点：

1. **顺序 = 成本排序**：接触测试最快最便宜所以最先测，margin 最贵所以最后测。fail-stop 的意思是"第一个 fail 即停"——坏 die 不配跑完全流程；
2. **每个菱形就是一个 spec 限值**：程序里写的是 `if (读数 ∉ [下限, 上限]) → fail`。你调过的那些 limit，在硅上对应的就是这些菱形；
3. **唯一有回路的分支是修复**：MBiST 发现坏位 → 诊断到行/列/lane → 可修就走冗余替换（激光/e-fuse/PPR）→ **回到 ④ 复验**。修不好才淘汰。这解释了数据里"修复率"为什么是独立统计的一列。

bin 顺序与物理含义（Bin1–7）出自 Edusemi-Plus（项目既有归档）；三星 EDS 官方口径的 ET 测试即对"晶体管/电阻/电容/二极管"做 DC 参数测试——与图中 ①–③ 同一件事。

## 三、物理电路图：电流实际走哪条路

![物理电路图：探针到阵列的实物路径剖面](/diagrams/test-physical-circuit.svg)

主剖面是 **PSWT（堆叠后晶圆测试）** 的姿态：探针从 base die 背面扎铝焊盘，电流的真实路径是：

```
ATE·PMU → 线缆 → 探针卡 → 针尖 → 铝焊盘 → ESD 二极管对 → VDD/VSS 轨 → DRAM 阵列列 / TSV 链（逐层）→ 回流
```

右侧三个小块是**同一颗堆栈在三个工序的三处下针面**：预堆叠 CP 用牺牲焊盘、堆栈 at-speed 用 176 个 JEDEC 直接访问凸点、PSWT 用 base die 背面铝焊盘。找数据时先问"哪个插入点"，就知道电流走的是哪条物理路径——这也是谱系主键里 `insert` 字段的物理出处。

## 四、失效级模拟电路图：六种失效各自的测量环路

与 3D 模型 L3 的失效选择器一一对应（选中即显示对应图）。六张图共用同一个判定句式：**施加以 PMU 为源 → 电流/电压沿被测路径流动 → 读数与限值窗比较 → bin → 处置**。所有读数为示意量级（限值随器件 spec 与量程档变化）。

### ① 接触开路（FIMV：加流测压，电压顶到钳位）

![接触开路：电流无路可走，电压顶到钳位](/diagrams/fault-open.svg)

看图要点：电流源推 +100 μA，但针尖–焊盘断开，电流无处可去 → 节点电压被推高到 FI 模式的钳位（1.50 V）→ 落在限值窗（0.45–0.75 V）上方 → Bin1，不进修复。

### ② 焊盘对地短路（同一测试，读数反向）

![焊盘对地短路：二极管被旁路，压差塌到 0](/diagrams/fault-padshort.svg)

看图要点：与①同一个测试、同一个限值窗，只是缺陷换成「焊盘–地金属桥」→ 电流全从桥走、二极管被旁路 → 读数 0.02 V 落在窗口下方。**①②合起来说明：一个 window 的上下两侧各对应一种物理缺陷。**

### ③ PowerShort（FVMI：加压测流，R = V/I 现场算）

![PowerShort：电源轨间缺陷桥连，电流远超限](/diagrams/fault-powershort.svg)

看图要点：换成加压测流——电源轨加 0.5 V 安全电平（防加坏好 die），好 die 只有 μA–mA 级寄生漏电，缺陷桥连时读数 180 mA → R = 0.5/0.18 ≈ 2.8 Ω，Ω 量级直接指认「桥连」而非「漏电」。

### ④ 输入漏电超标（灵敏量程才看得见）

![输入漏电：μA 级电流被灵敏量程抓出](/diagrams/fault-leak.svg)

看图要点：结构与①共用焊盘，但电流小六个数量级（12 μA vs 限值 1 μA）——PMU 必须切 μA 灵敏档才「看得见」。这就是 DC 三件套把 Leakage 单列一步的原因：量程不同、缺陷域不同。

### ⑤ 功能位失效（数字级：期望 vs 读出的离散比对）

![功能位失效：MBiST 写读比较与修复回路](/diagrams/fault-func.svg)

看图要点：DC 全过后不再看连续读数，而是 APG 图形的「期望 vs 读出」比对——弱电荷单元读出 1 ≠ 期望 0 → 坏位坐标进失效捕获存储 → 按 bank/行/列归因 → 可修走 fuse box 重映射并**回到写读比较复验**（图中唯一一条回路）。

### ⑥ TSV 开路 / lane 失效（一处断裂 = 整列失联）

![TSV 开路：断裂点以上整列 column fail，lane 重映射兜底](/diagrams/fault-tsv.svg)

看图要点：TSV 是纵向共用的——断一处不是坏一个位，而是「自断点向上整列无响应」；修复粒度是 lane/列而非位。这解释了数据里 column fail 为什么总与 TSV/修复率一起统计。
