## 01 触发：警报从哪里来

| 触发源 | 典型规则 | 第一动作 |
|---|---|---|
| SPC 判异 | 单点出限、连续 7 点同侧、2/3 点在 2σ 区、6 点连升/降（Western Electric/Nelson 规则族） | 查控制图 → 找判异 violated 的点对应的 lot/wafer |
| YMS 良率告警 | yield < 目标 −x pp，或 vs 滚动基线超限（阈值厂内定） | 确认告警口径（分母、窗口）再动手 |
| PAT/DPAT 超限 | 动态限值离群 die 数突增 | 区分"分布整体漂移"与"尾部离群增多"——两者根因方向不同 |
| FDC 参数越限 | 键合压力/温度/共面性轨迹超限 | 先查 FDC 触发时间与测试失效时间的先后 |
| 客户/下游反馈 | FT/SLT 逃逸、RMA | 走逃逸 case，倒查上游插入点数据 |

**触发后两个动作先于一切分析**：① hold 涉事 lot、隔离在制品、需发货的走加严检验；② 冻结证据——原始 WPFile/STDF、KLARF、tester log、recipe 版本快照、针卡 ID 与 touchdown 计数、该批物料的 MES 谱系。证据不冻结，后面所有分析都在被污染的现场上做。

## 02 前 2 小时：先核查数据有效性，再怀疑产品

新手最大的坑是把"测试系统说谎"当成"产品坏了"。数据有效性核查清单：

| # | 核查项 | 具体动作 | 指向 |
|---|---|---|---|
| 1 | datalog 完整性 | 文件数 vs 机台产出数；解析器报错日志 | 缺文件=统计口径假象 |
| 2 | 程序/limit 版本 | PRR/MIR 的 JOB_REV vs MES 工单绑定；limit diff | 版本切换造成的"假掉良" |
| 3 | 分母定义 | gross die / net die / edge exclusion；口径是否与基线一致 | 分母变化伪装成良率下跌 |
| 4 | 复测记录 | retest 标志位是否被正确解析；同一 die 多条 PRR 的去重规则 | 复测未去重 → 良率虚低/虚高 |
| 5 | 机台状态 | 校准到期日、温度实际值 vs 设定值、prober 对准/零点 | 测试条件漂移 |
| 6 | 报表本身 | 用原始数据手工复算一个 lot 的良率 | YMS 统计 bug |

**基本盘七问**（初报的事实骨架）：

1. 掉多少：基线 X% → 当前 Y%，差 Z pp；影响 N 个 lot / M 片 wafer
2. 何时开始：第一颗异常 wafer 的测试结束时间（END_T），不是发现时间
3. 哪里掉：产品 × 插入点 × 工站，一层层定位
4. 是否单点：单 lot？单 wafer？单 tester？单针卡？单 site？——"单点性"是后续一切假设的骨架
5. 有什么改动：4M 清单（机：维修/换针卡/校准；料：凸点批次/基板批次；法：recipe/limit 变更；人：班次/新员工）
6. 测试系统本身是否在撒谎：见上表 1–6
7. 客户影响：涉事 lot 是否已放行、是否需追回

## 03 Day 1：工程师真实打开的十类数据视图

每类给出：数据来源 → 看什么 → 判定指向。这是"真实要看的数据"的核心清单。

### 3.1 良率趋势：by lot，不是 by day

- 来源：PRR 聚合（`yield_rate_fpy`，首插入口径）+ MES 谱系
- 看什么：从哪个 lot 起跳变；跳变是阶跃（→变更点）还是渐变（→磨损/漂移）
- 指向：阶跃对齐 4M 变更点 → 变更归因；渐变 → 耗材寿命/参数漂移

### 3.2 First-fail bin Pareto vs 基线

- 来源：PRR 的 bin + first-fail 归一（分母 = 失败 die 数）
- 看什么：top bin 的占比位移（vs 30 天基线）；位移量 ≥5pp 且 n≥690 失效/组才有统计意义
- 指向：bin1（Open/Short）↑ → 接触/探针/焊盘类；bin4（Function）↑ → 阵列/键合类；bin2/3（PowerShort/Idd）↑ → 短路/漏电类。fail-stop 删失：bin1 暴涨会压低后面所有 bin 的表观计数，必须用 first-fail 口径
- 站内依据：《[T5833 与 Magnum 7H](/notes/hbm/testers-wpfile-binmap/)》§五

### 3.3 Wafer map 空间签名

- 来源：PRR 的 `X_COORD/Y_COORD` + KLARF
- 看什么：失效 die 的空间模式

| 签名 | 形态 | 指向 |
|---|---|---|
| 随机点 | 全片散布 | 随机缺陷 → 前道/颗粒 |
| 边缘环 | 沿 wafer 边缘一圈 | 边缘工艺/切割/SealRing/边缘探扎 |
| 列/行签名 | 整列/整行失效 | TSV/lane、冗余列、扫描链 |
| 聚簇 | 局部成团 | 局部工艺异常（粒子、键合局部压力） |
| 径向渐变 | 中心好边缘差 | 减薄均匀性/凸点高度共面性 |

### 3.4 Site × yield 表

- 来源：PRR 的 `HEAD_NUM/SITE_NUM` 聚合
- 看什么：多 site 并行中哪个 site 系统性差；先做 site × 径向位置混杂检验（排除"某 site 分到边缘 die"）
- 指向：层内显著 → 针卡该 site 针尖/pogo/通道；全 site 同步差 → 产品或共同条件

### 3.5 Tester × yield 对照（最快的二分实验）

- 来源：同产品、同窗口、不同 tester 的良率
- 看什么：同 lot 分批在不同 tester 上测（或历史同产品数据）是否 tester 间差异显著
- 指向：tester A 差 B 好 → 测试系统问题（针卡/log 板/校准）；都差 → 产品/物料/共同变更。两比例检验：差 2pp、每组 n≈1,900 die 才有 3σ 分辨力（C 级算例，见《[测试入门四个高频误区](/notes/hbm/test-beginner-four-questions/)》§02）

### 3.6 Retest / reprobe recovery 矩阵

- 来源：同一 die 的多次 PRR（PART_FLG bit0/1 覆盖标志 + first/final 口径）
- 看什么：fail die 复测后的回收率；回收的 die 集中在哪个 bin、哪个 site
- 指向：**高回收（>60%，C 级经验阈值）→ 接触类问题（针尖污染/磨损、共面性），不是真实产品失效**；低回收 → 真实失效，转产品归因。这一张表经常直接终结方向争论

### 3.7 参数直方图 / DPAT 离群

- 来源：PTR（每测试项实测值）
- 看什么：关键参数分布 vs 基线——整体漂移（mean shift）还是尾部变厚（离群增多）；漂移方向（接触电阻 ↑？Vmin 左移？Idd ↑？）
- 指向：分布漂移**先于**良率塌陷——即使良率只掉 0.5pp，参数漂移可能已达 2σ；这也是加严/围堵的分选依据

### 3.8 4M 变更点清单

- 来源：MES（机台维修记录、recipe 版本历史）、EAP（针卡装卸事件）、物料系统（批次）
- 看什么：异常起点前 72h 内的所有变更，按"距异常 lot 的谱系距离"排序
- 指向：变更点与跳变时间对齐 → 变更归因；无变更 → 磨损/漂移/批次类

### 3.9 谱系 join：把测试失效 join 回上游

- 来源：MES 谱系（lot→wafer→die→stack 组成表）+ EAP 设备日志
- 看什么：异常 die 曾经过哪些键合机台、哪张减薄批次、哪根针卡（touchdown 计数）、哪个凸点批次
- 指向：fail 率 vs touchdown 计数的散点/回归——剂量-响应关系是针卡类根因的最强证据之一

### 3.10 测试条件矩阵

- 来源：程序数据 + 机台 log
- 看什么：hot/cold 哪个温度挂、voltage corner（VDD min/nom/max）哪个挂、测试时间是否异常变长
- 指向：仅 cold 挂 → 接触/温度敏感类；仅 VDD min 挂 → 弱件/margin 类；测试时间突增 → 程序行为变化

## 04 分析方法：从假设清单到根因

### 4.1 Is / Is-Not 矩阵（KT 法，比鱼骨图先做）

对"什么有问题/没问题、哪里、何时、程度"逐格填写，用差异点收窄原因域。这是 8D D2 的核心动作，也是避免漫无目的鱼骨图的纪律。

| 维度 | Is（有问题） | Is-Not（没问题） | 差异点→指向 |
|---|---|---|---|
| 什么 | bin1 first-fail 3.9% | bin4 正常 | 接触类而非功能类 |
| 哪里 | tester 2 的 site 3/7 | 同机台其他 site | 针卡 site 相关 |
| 何时 | 08-21 起的 lot | 08-20 前的 lot | 变更点在 08-20 夜班 |
| 程度 | FPY -4.4pp | final 只 -1.2pp | 复测回收高 → 接触类 |

### 4.2 假设优先级 = 先验概率 × 验证成本

列出全部候选假设，按"行业先验 ×（数据已支持度）/ 验证成本"排序验证顺序。CP 端低良的先验示例（**C 级，行业口头惯例，仅示意排序逻辑**）：针卡磨损/污染 ≈ 接触/共面性 > 程序/limit 变更 > 机台校准 > 物料批次 > 真实工艺异常。**排序逻辑是方法论（保留），具体百分比是示意（勿引用）**。

### 4.3 统计纪律

- 任何"A 比 B 差"的结论必须过两比例检验：报告差值 + 95% CI + n；差值小于 2×CI 半宽不下结论
- 多 site/多 tester 同时比较 → 多重比较校正（FDR 或 α/n）
- 相关分析（fail 率 vs TD 计数）报告 r² 与残差，警惕混杂（针卡与机台绑定时，先做 tester 间对照）

### 4.4 双根因：发生根因 + 流出根因

真实 8D 的 D4 必须回答两个问题：**为什么发生**（occurrence：针尖磨损+清洗周期过长）与**为什么流出**（escape/非检出：SPC 为什么没在第一片 wafer 就报警、围堵分选为什么没拦住）。只答发生根因的 8D 会被 QE 打回——这是 case 报告最常见的退回原因。

### 4.5 五个常见陷阱

1. 先入为主：锁定第一个想到的原因后只找支持证据（确认偏误）——用 Is/Is-Not 强制对称
2. raw bin Pareto 误读：fail-stop 删失下的计数偏差（见 §3.2）
3. 把复测回收当真实良率：FPY 与 final 混用，掩盖接触类问题
4. 样本量不足下结论：日失效 n=40 就宣称 bin 占比"翻倍"
5. 只做统计不做实物：数据相关不等于根因，缺 FA 证据链的 case 关不掉（见 §06）

## 05 分析报告怎么写：8D 逐节写法

| 节 | 内容 | 必含要素 | 常见退回原因 |
|---|---|---|---|
| D0 征兆响应 | 警报来源、发现时间线 | 触发规则、第一动作时刻表 | 缺时间线 |
| D1 团队 | CFT 成员与角色 | TE/QE/设备/产品/计划，明确 Champion | 单部门闭门造车 |
| D2 问题描述 | 5W2H + Is/Is-Not 矩阵 | 基线定义、分母口径、影响面（lot/wafer/die 计数）、客户影响 | 良率口径不清 |
| D3 临时围堵 ICA | hold/分选/加严/全检 | 围堵覆盖范围（已流出多少、召回多少）、ICA 有效性数据 | 只写"已 hold"不写流出面 |
| D4 根因 | **双根因** + 证据链 | 发生根因 + 流出根因；每条假设的验证结果（证实/证伪） | 只有发生根因；假设未逐条关闭 |
| D5 永久对策 | 选定的 PCA | 对策与根因的对应关系；多选一时的比较依据 | 对策与根因无对应 |
| D6 实施与验证 | 实施记录 + 有效性数据 | 验证实验设计、连续 N lot 数据、SPC 恢复证据 | 无量化有效性 |
| D7 预防 | 体系化 | FMEA 更新、SPC 规则新增、作业指导书、培训记录、横展清单 | 无横展 |
| D8 关闭 | 签核 | QE 签核；（客户 case）客户书面同意；团队表彰 | 缺客户批准 |

图表规范（报告最低配图）：① by-lot 良率趋势（标基线带与变更点）② first-fail bin Pareto（含样本量与 CI）③ 异常/正常 wafer map 对比 ④ site/tester 分解 ⑤ 关键相关性图（如 fail 率 vs TD 计数）。每张图必须标注：样本量、口径、基线窗口。

**判定措辞分级**（报告语言的纪律）：

| 措辞 | 允许的证据强度 |
|---|---|
| 已证实（confirmed） | 证据三角闭合：统计相关 + 物理 FA + 再现/消除实验 |
| 高度可能（highly likely） | 统计相关 + 机理解释，缺再现实验 |
| 待验证（hypothesis） | 仅有相关性，样本量不足或存在未排除混杂 |

## 06 如何验证：证据三角

根因只有走完三角才算"确认"：

1. **统计相关**：假设因子与失效在数据上显著相关（§4.3 纪律）
2. **物理证据（FA）**：X-ray（键合空洞/对准）、SAT（分层/裂纹）、光学/SEM 显微（针尖磨损形貌）、切片 + SEM/EDX（污染成分）——FA 结果必须与电测签名兼容（列签名 → TSV 开路，而不是"什么都没找到"）
3. **再现与消除实验**：
   - 再现：故意用嫌疑因子打已知良 lot（如用超期未清洗的针卡）→ 失效签名复现
   - 消除：更换/修复嫌疑因子 → 良率回基线
   - 剂量-响应：失效率和暴露量（TD 计数/使用时长）单调相关

**对策有效性验证（D6）**：连续 ≥3 个 lot（或厂内规定的 wafer 数，C 级）FPY 回到基线 ±0.5pp 内；retest 率回落；关键参数 SPC 连续 ≥25 点受控；bin 分布与基线无显著差异（两比例检验）。以上数值为 C 级示例——正式判据由 QE 按产品与客户协议设定。

## 07 如何确认与关闭 case

**关闭判据清单**（全部满足方可提交关闭，数值为 C 级示例）：

- [ ] 双根因均被证据三角证实（或流出根因对应的所有逃逸 lot 已完成围堵处置）
- [ ] D6 有效性数据达标：连续 3 lot / 20 wafer 达基线 ±0.5pp
- [ ] SPC 连续 25 点受控，无新增判异
- [ ] 围堵措施撤除后无复发（撤 ICA 后至少 1 个生产周期）
- [ ] D7 体系化完成：FMEA 行更新、SPC/警报导入、SOP/检查表修订、相关机台/产品横展清单关闭
- [ ] 知识库归档：case 编号、时间线、数据快照、FA 报告入知识库（对接站内知识库规划，见《[数据科学落地方案](/notes/smart-mfg/data-science-roadmap/)》S4）
- [ ] 签核链：TE → QE；（客户 case）客户书面批准

**重开条件**：监控窗口内（惯例 30/60/90 天，按严重度）同根因复发 → 立即重开并升级一级处理；复发即说明 D4/D5 至少一个不成立，禁止"二次围堵了事"。
