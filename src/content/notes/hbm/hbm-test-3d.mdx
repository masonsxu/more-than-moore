## 1. 测试区域 vs GPU 通讯区域：同一颗堆栈的两个面

HBM 堆栈的**通讯电路**和**测试电路**在版图上是物理分区的。最权威的量化口径来自 SWTest 2017 上 SK hynix + FormFactor + Advantest 的联合论文，他们对 JEDEC HBM2 版图做了完整普查：

| 凸点类别（HBM2，每堆栈） | 数量 | 归属 |
|---|---|---|
| IO micro-bump | 1728 | **GPU 通讯区域**：1024-bit 数据 + 控制，经 base die → interposer → GPU |
| 电源 / 地 micro-bump | 1056 / 1030 | 供电网络（3 组电源域） |
| **直接访问（Direct Access）micro-bump** | **176** | **测试专用**：ATE 对堆栈做 at-speed 原生模式测试的入口 |
| 合计 | 3990（55 μm 间距，27.5×48 μm 交错；阵列 6022×2832 μm） | — |

（来源：[SWTest 2017，S09_01](https://www.swtest.org/swtw_library/2017proc/PDF/S09_01_Nhin_SWTW2017R2.pdf)；摘录归档 [`public/sources/hbm-test/2017-06_swtw_hbm2-kgs-test-cell.md`](/sources/hbm-test/2017-06_swtw_hbm2-kgs-test-cell.md)）

探针从哪里下针，按工序分三个位置：

| 扎针位置 | 工序 | 说明 |
|---|---|---|
| DRAM 裸片正面的 DFT / **牺牲测试焊盘** | 预堆叠晶圆 CP | JEDEC 在 HBM micro-bump 版图中预留了牺牲测试焊盘空间（semiengineering，2026）；量产用它、开发阶段直接扎 micro-bump（FormFactor，2026） |
| **JEDEC 直接访问凸点**（176 个） | 堆栈 at-speed 测试 | 8 通道同时原生模式功能/性能测试，>2.4 Gbps（2017 年实测口径） |
| **base die 背面的铝焊盘** | PSWT（堆叠后晶圆测试） | 铝焊盘布在 base die 背面 micro-bump 版图的预留空间里，测试时堆叠晶圆翻转、从背面下针（Teradyne / semiengineering，2026） |

两处关键取舍，都有数字：

- **焊盘 vs 凸点**：SWTest 2025 的对照——micro-bump 直接扎针「8 通道可同时测、接近实际使用条件」，但「deep coining 无法用于量产、并行度低」；DFT 焊盘「不伤凸点、可大并行」，但「测试条件偏离实际使用」。Aehr Test 给出成本口径：牺牲焊盘拉开间距后，**探针卡可省约 80% 成本**（免掉 50 万美元级探针卡）（均见 semiengineering 2026 与 SWTest 2025，摘录已归档）。
- **与 GPU 通讯区域的物理隔离**：测试焊盘/凸点在版图上是独立预留资源，通讯走 IO 凸点场。这就是模型里红色（直接访问凸点）、银色（PSWT 铝焊盘）、金色（GPU 通讯 IO 场）三种颜色分开的原因。

## 2. 电路级：12 层堆栈里 ATE 信号怎么走

### 2.1 先看全流程有哪些插入点

| 插入点 | 测什么 | 速度 / 并行度 | 出处 |
|---|---|---|---|
| DRAM 核心晶圆 CP（每层各自） | DC 参数、弱位、修复 | ~100 MHz 弱位筛选 + 修复；64–128 site；单针 2.5 g、整片约 50 kg | Neumonda，via semiengineering |
| 晶圆级烧灼 WBI | 早期失效 / 氧化层弱项 | 高温 + AC/DC 应力 | Samsung EDS、Aehr Test |
| base die 晶圆测试 | DFT 链路：IEEE 1500 / direct access、MBiST、TSV 连通性、PHY | 逻辑 ATE 内容 | semiengineering，2026 |
| Pre/Post Laser 修复 | 冗余替换与复验 | — | Samsung EDS |
| PSWT（堆叠后晶圆测试） | 整链 DC→高低温→高频 | 逐级淘汰保持效率；12 层全流程 3–12 次插入 | SWTest 2025 / semiengineering |
| 单颗堆栈测试（die carrier） | 全速、多温、单次接触全覆盖 | 4 GHz、对准 ±1.4 μm、64 并行 15 W 时 Tj 升 ≤3 ℃ | SWTest 2025 |
| 封装最终测试 | 整包验证 | 诊断透明度最差，失效可能来自单颗裸片、层间连接或堆栈交互 | FormFactor，2026 |

### 2.2 一次测试的信号路径（对应模型的「ATE 信号链路」模式）

以 12 层堆栈（D0 贴 base die，D11 在顶）为例：

1. **ATE**：算法图形发生器（APG）产生存储测试图形，失效捕获存储（error catch RAM）实时记录失效位——修复分析在线完成（Advantest Oda，via semiengineering）。
2. **探针卡**：CP 阶段悬臂/垂直 MEMS 针落在 DFT/牺牲焊盘上；高速堆栈测试用 MEMS 垂直针直接接触直接访问凸点（HFTAP 已在量产验证 >3 GHz、128 DUT，FormFactor）。
3. **下针面**：焊盘 →（堆叠后测试则经 base die 背面铝焊盘翻转进入）。
4. **base die 的 DFT 电路**：JEDEC direct access 总线 / IEEE 1500 包装接入——base die 是堆栈唯一访问通路，MBiST（通常可编程）接管各层 DRAM 测试，同时验证 TSV 连通性与 PHY。
5. **TSV 链上行**：测试激励经 TSV 逐层穿过 D0→D11，每层的阵列/读出电路被依次激励；任何一层失效都能在失效捕获存储里留下位图。
6. **诊断读出**：MBiST 报告到 bank / 行 / 列粒度（Synopsys），支撑冗余修复（激光修复在晶圆级、e-fuse 到封装级、JEDEC PPR 每 bank 一行）与 TSV/lane 修复；修复后复测。
7. **读出回程**：沿同一链路返回 ATE 比对；8 通道同时跑数据时输出眼图明显收缩（SWTest 2017 实测），所以 at-speed 筛选必须在全通道激活条件下做。

两速原则贯穿始终：第一插入低速（~100 MHz）抓弱位做修复，第二插入（KGD）走高速接口全速跑——「KGD 通常不支持最高速度档」的原因是低并行高速探针卡的成本约束（Neumonda）。

## 3. 失效分类：如何区分 PowerShort、SealRing、Crack、Bridge（及 FRL、FSA）

区分的原理是同一个：**每类物理失效在「电测签名 × 空间签名 × 首次暴露的插入点」三个维度上有稳定组合**。能查到公开依据的四类如下：

| 失效类型 | 物理根因 | 电测如何区分 | 空间/检查签名 | 首次暴露点 |
|---|---|---|---|---|
| **PowerShort** | 电源网络与地之间被缺陷（金属/粒子/键合材料挤压溢出）短接 | DC 参数测试三件套之一（Power Short / Contact / Leakage）：加压测流或加流测压，电流远超限即判——属 bin 分类的第一格「Open/Short」致命类，fail-stop 流程最先测 | 无位置结构，整片任意分布；**不进修复流程，直接淘汰** | 预堆叠 CP 最早暴露 |
| **SealRing** | 裸片边缘密封环（应力保护 + 阻挡裂纹与腐蚀的金属环结构）受损：探痕、崩边、切割微裂纹延伸 | 边缘结构相关的开路/漏电在 CP 的 OS/漏电项暴露；IPFA 2021 实证：inline E-test 在划片线结构上的探痕可在晶圆分选阶段诱发失效，「即使探针与有源区保持安全距离」 | **沿裸片周边分布**的失效环/边缘聚簇是判别特征；与探针卡针位布局相关 | CP（探痕型）；切割/减薄后复测（应力型） |
| **Crack** | 减薄与切割引入机械应力，「加剧已有裂纹、滑移与划伤」（semiengineering 原句）；薄化到 30–60 μm 的 DRAM 裸片更敏感 | 电测签名随裂纹路径：跨线切割→开路簇、穿氧化层→漏电簇；与 SealRing 的区别在**穿芯**而非沿边 | X-ray/SAT 检查：Bruker 在 die-attach 后做 100% X-ray 检查 HBM 隐藏缺陷——30% 采样把 excursion 缩到约 7 天，100% 采样再拿 1.7% 良率、缩到 2 天 | 减薄/切割后、PSWT/FT 阶段放大 |
| **Bridge** | 相邻凸点/走线桥连：TC 键合「造成开路、短路、head-in-pillow 和高阻连接」（semiengineering 原句）；凸点形变、焊料挤出 | 邻网短路在 DC（邻针间测阻）与功能图形（相邻位翻转）都能暴露；键合类桥连在**预堆叠 CP 通过、堆叠后失败**——跨插入点差分即定位到键合 | 凸点 CD/高度量测 + 凸点顶残留检测（Onto）；BLT 失衡→non-wet / 焊料挤出（Bruker）；通道失效走 lane repair | PSWT / 堆栈测试新暴露 |

> **Blocked: need confirmation on FRL / FSA 的全称与判定条件。** 截至 2026-09-25 的公开检索（英文/日文/韩文，含 SWTest 论文库、IEEE、专利库）未找到这两个缩写在 HBM/DRAM 测试语境下的权威定义，不排除是产线内部 bin 名。按同一判别框架，它们应落在「电测签名 × 空间签名 × 插入点」的组合上：拿到全称与 bin 定义后即可填入上表，方法不变。本笔记不猜测、不杜撰。

共同的分析流程：**bin 分布（哪一项先 fail）→ 位图/晶圆图空间签名（点/环/边/聚簇）→ 跨插入点差分（CP 过了 PSWT 挂 = 键合类；CP 即挂 = 裸片类）→ 物理失效分析（X-ray / SAT / 切片）闭环**。这套「电测症状 → 物理损伤」的投影关系是行业通用方法论（Edusemi bin 分类：晶圆测试 bin 应读作「底层物理损伤的电学症状」，归档见来源清单）。

## 4. 设计良率 vs 封装良率：测试手段与失效分析

### 4.1 两者的边界

| | 设计良率（晶圆/裸片侧） | 封装良率（堆叠/组装侧） |
|---|---|---|
| 决定阶段 | 晶圆制造 + 设计余量，CP/EDS 阶段见分晓 | 堆叠键合（TSV / μbump / MR-MUF / TC-NCF）、减薄切割、组装 |
| 典型限制 | 随机缺陷 + 系统性/设计边缘性（先进节点系统性问题主导） | 对准（单微米级）、键合质量（开路/短路/HIP/高阻）、裂纹/空洞/分层、翘曲 |
| 复利效应 | 单颗裸片良率 | **堆叠放大**：单 die 95% 时 16 层综合良率 44%（0.95¹⁶）；base die 坏一颗，上面 8–16 层全报废（Aehr Test） |

### 4.2 设计良率：测试手段

1. **EDS/CP 全流程**（三星官方口径的五步）：ET 参数测试 + WBI 烧灼 → Pre-Laser 高低温双温 → 激光修复 + Post Laser 复验 → 贴膜减薄 → Inking 标记。目的明确：「尽早发现晶圆制造工序或设计的问题，反馈给工艺与设计团队」。
2. **Bin 分类体系**：fail-stop 顺序 Open/Short → Standby/Active Idd → Function → Pause/Disturb Refresh → Margin，每个 bin 对应独立物理失效域（0.25 μm 世代骨架沿用至今）。
3. **修复率管理**：冗余行/列占裸片面积 5–10%；晶圆级激光修复、封装级 e-fuse、JEDEC PPR 每 bank 一行——「没有冗余，晶圆级良率会显著更低」。
4. **统计筛查与图形识别**：PAT/DPAT/GDBN 离群剔除、SPC（详见站内报告[《测试数据分析：从 ATE 到筛选决策》](/reports/hbm3e-hbm4e/test-data-analytics.html)）；ML 空间图形识别（SPR）把工艺/机台系统性问题自动归类，SkyWater 案例**工程师效率 +25%**。
5. **系统性良率优先**：先进节点「系统性缺陷与参数波动在量产初期就存在」，GF 14nm 案例——设计版图弱点（weak point）分析 + OPC 修正拿回晶圆边缘 >5% 良率损失（PDF Solutions / GF ASMC，via semiengineering）。

### 4.3 封装良率：测试手段

1. **多插入点递进筛选**：12 层堆栈全流程 3–12 次插入（视封装厂质量档位）；每层堆叠后或每 2/4 层插入一次测试；逐级淘汰保持效率（SWTest 2025：90/80/70% vs 单次 100% 的取舍）。
2. **PSWT / KGS**：翻转扎针 base die 背面铝焊盘，DC → 高低温 → 高频逐级；MBiST/direct access 测整链，每次插入做 TSV 修复。
3. **单颗堆栈测试**（die carrier）：全速 4 GHz、多温、单次接触全覆盖；对准 ±1.4 μm；64 并行 15 W 时 Tj 升 ≤3 ℃（FormFactor/Advantest 2025）。
4. **检查互补**：凸点 CD/高度量测、凸点顶残留检测（Onto）；X-ray 采样率与良率/excursion 的量化关系（Bruker：30% 采样→约 7 天 excursion，100%→+1.7% 良率、2 天）；SAT 查裂纹/空洞/分层。
5. **终测前的经济学**：HBM 占 AI 芯片成本近一半；典型 1 GPU + 8 堆栈，坏一颗在终测才暴露代价最高——这是「测试左移」的全部动因（Teradyne / semiengineering）。

### 4.4 失效分析：数据与物理双轨

- **数据侧**：STDF 逐 die 参数 + bin 分布 → 位图/晶圆图空间签名（点失效/边缘环/聚簇/条带）→ 跨插入点差分定位责任工序 → 良率模型（负二项）与批次限（SYL/SBL）监控。
- **物理侧**：X-ray（隐藏缺陷、键合偏移）→ SAT/C-SAM（空洞、分层、裂纹）→ 切片/EMMI 类定位到点 → 与 MBiST 的 bank/行/列诊断对齐（Synopsys：诊断必须「differentiate and isolate to do physical failure analysis」）。
- **闭环**：Onto McIntyre——BiST 位图 + 位图模式分类器仍是「把在线缺陷匹配到单元级影响」的金标准；追溯与性能匹配（慢内存装进高性能封装会拖垮整包 ASP）跨厂区贯穿。

- **方法论口径**：bin 分类与 fail-stop（来源 8）为教学整理，代表通用实践而非某厂现行程序。

- 本文 3D 模型为示意比例；翻转姿态仅示意 PSWT 下针面，实际由探针台完成。
