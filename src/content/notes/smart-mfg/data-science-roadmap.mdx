## 方向标：先进封装厂的智能制造

本项目聚焦的 HBM 先进封装（3D 堆叠）是先进封装中制造链条最长、工序互锁最强的一支：减薄 → TSV → 微凸点 → 堆叠键合（MR-MUF/TC-NCF，混合键合在储备）→ 塑封 → 电测（晶圆 CP → 堆叠 PSWT → KGSD）→ 检查与量测 → 2.5D 组装。每个环节都在产数据：设备参数、过程量测、AOI 图像、测试结果（STDF/KLARF）。

智能制造的本质不是"上模型"，而是**让每一道工序的决策从经验驱动变成数据驱动**，分五级阶梯：

| 阶梯 | 形态 | 判据 |
|---|---|---|
| L0 人工报表 | Excel 手工拼、事后追溯 | 数据在机台里睡觉 |
| L1 自动采集与可视化 | 设备联网、看板自动更新 | 数据 T+1 可见 |
| L2 统计过程能力 | SPC、PAT/DPAT、FDC 雏形 | 异常被规则发现 |
| L3 预测与优化 | 良率预测、缺陷分类、预测性维护 | 模型给出量化建议 |
| L4 闭环智能 | 调度优化、自适应测试、知识库 | 建议进入受控执行 |

标准语境：设备联网遵循 SEMI E5（SECS-II）/ E30（GEM），数据流映射 ISA-95 分层（L1 设备 → L3 MES/分析 → L4 计划）（级别 A，公开标准）。

## S0 数据地基（M0–3）

**做什么**

1. 设备联网盘点：EAP（SECS/GEM，SEMI E5/E30）与 EDA（SEMI E134/E164）两条通道逐台确认接口开放情况，产出《接口可用性台账》；不开放的机台列清单走厂商开通或文件落地（WPFile/STDF）兜底
2. 三类数据源接入原型：测试结果（厂内 WPFile / 国际 STDF，字段语义同构，解析器按厂内实际格式选型）、缺陷/检图（KLARF、AOI 图像索引）、过程量测（厚度/翘曲/凸点高度）
3. 主数据统一：机台、产品、批次、lot/wafer/die/插入点谱系、测试程序版本——一张主键表
4. 数据分级 L1–L4 落地：客户 IP 数据的存储路径与权限从第一天就隔离（封测厂审厂必查项）

**产出**：采集覆盖率台账（按机台型号）、统一数据字典 v1、单机台端到端原型管道（STDF zip 进 → die 级 Parquet 出 ≤5 分钟）。

**对研发（NPI）**：新机台/新基板 bring-up 期的数据 100% 可回放，工程调试不再依赖截图和口头描述；NPI 数据与量产数据同构，学习成本一次性付清。

**对量产**：人工取数从"导文件 + 拼 Excel"变成一次查询——这是后续一切自动化的地基，本身已把高频取数请求消化掉一半（假设，以基线实测）。

**KPI**：接口覆盖率 ≥90%（试点线）；原型链路 ≤5 分钟/份；数据字典通过 TE/QE 评审。

## S1 可视化与自动报表（M3–6）

**做什么**

1. 三张核心看板：良率（按机台/产品/插入点）、OEE 与瓶颈工序、品质逃逸追踪
2. 日报自动化：T+1 09:00 前自动产出，替代人工日报
3. 异常推送：良率/参数越界时定向通知 TE/QE，替代"谁想起来谁去看"

**产出**：看板系统 + 自动日报 + 告警规则集（阈值取自产线确认）。

**对研发**：NPI 阶段的 correlation（CP→FT→SLT 跨插入点）从手工比对变成同源数据切换视图；工程变更（程序版本、limit 调整）前后对比有据可查。

**对量产**：掉良率/掉速从"次日发现"提前到小时级；管理层数字口径统一（单一 Gold 层），结束各部门数字打架。

**KPI**：日报时效 T+1 09:00（连续 20 工作日）；手工取数请求 −50%（对比 S0 基线）；看板周活工程师 ≥5 人。

## S2 统计过程能力（M6–12）

**做什么**

1. SPC 控制图上线：键合后凸点高度、减薄厚度、翘曲等关键参数按工序建控制限
2. 测试端统计筛查：PAT/DPAT 动态限值（AEC-Q001 方法论，按 lot 分层）+ GDBN（Roehr, ITC 2000）
3. FDC 雏形：键合机/研磨机参数漂移的规则化监测（压力、温度、共面性的偏移与漂移检测）
4. 逃逸追溯链：die → lot → 工位 → 参数 → 机台，秒级查询

**产出**：统计基线引擎（PAT/DPAT/SPC/FDC 规则）+ 异常月报 + 追溯 CLI。

**对研发**：工艺窗口确认从"抽几个点看散点图"变成 CPK/PPK 全量统计；DOE 之前先用历史数据筛因子，实验次数下降（假设 20–30%，以实际项目核算）。

**对量产**：缺陷拦截从"终检"前移到"过程"；测试端离群件不再流入下道——按 1-10-100 法则（Labovitz & Chang 1992），工序内拦截的成本是流出后处理成本的 1/10 量级；逃逸分析从周级缩到分钟级。

**KPI**：试点 device PAT 全量上线；误报率基线建立（人工抽检 ≥200 die/月）；逃逸追溯响应分钟级；关键工序 SPC 覆盖 ≥80%（假设基线）。

## S3 预测与优化（M12–18）

**做什么**

1. 良率/参数预测试点：GPR 预测 Vmin 与关键参数（Pan et al., JETTA 2024 双预测器思路），上游 CP 数据前馈 FT
2. AOI 缺陷自动分类：CNN（WM-811K 做能力基线，可溯源最高 98.56%，Bao 2024；产线数据重训后另行评测），人工复判只看模型低置信样本
3. 预测性维护（PdM）：键合机、研磨机的参数漂移 → 故障/停机预测，备件与保养计划联动
4. 测试调度优化：多插入点测试的下件组合与顺序优化（先规则化，再算法化）

**产出**：3 个模型试点报告（预测/AOI/PdM）+ 各自的上线/下线判据。

**对研发**：NPI 学习周期缩短——相似产品的历史档案可直接给出初版工艺窗口与测试 limit 建议；AOI 分类器让新品缺陷库冷启动更快。

**对量产**：AOI 人工复判量下降（目标 −40%，假设）；PdM 把计划外停机转为计划内保养（目标 unplanned downtime −20%，假设）；测试调度优化直接换算成机台产出与交付准交率。

**KPI**：预测模型达预设 AUC/召回（按产品分别设定，禁用数据集精度作承诺）；AOI 复判量 −40%（假设）；PdM 提前预警 ≥70%（假设，以 6 个月故障回放验证）。

## S4 闭环智能（M18–24）

**做什么**

1. 调度闭环（APS）：以 S1–S3 的数据与预测为输入，排产建议进入每日计划评审
2. 自适应测试闭环：PAT 基线 + 预测模型 → 测试项/limit 调整建议；**双闸门执行**——品质 MRB 唯一放行 + 客户质量协议评审，模型不自动放行
3. 工程知识库：LLM 检索工艺档案、8D 报告、已核对调研笔记（本仓库即原型），新工程师查询从"问老师傅"变为可溯源检索
4. 数字孪生雏形：键合/电测两个关键工位的参数-结果仿真关系数据化，为下一个 24 个月的虚拟 DOE 铺路

**产出**：调度试点、自适应闭环试点（单客户联合）、知识库上线、孪生数据集 v1。

**对研发**：NPI 周期缩短——新品导入复用历史相似产品档案（工艺窗口、典型失效模式、测试重点），knowledge 复用率第一次可度量。

**对量产**：单位成本与品质双指标同时改善：调度优化提产能、自适应测试省测试时间并拦截离群件、知识库降低对个体经验的依赖（单人巴士因子风险对冲）。

**KPI**：闭环建议采纳率（目标 ≥60%，假设）；自适应试点测试时间节省（目标 ≥5%，假设）；知识库月活 ≥50% 工程师（假设）；NPI 平均周期对比 S0 基线。

## 研发 vs 量产价值矩阵

| 阶段 | 对研发（NPI）的核心价值 | 对量产的核心价值 |
|---|---|---|
| S0 数据地基 | 数据 100% 可回放，bring-up 不靠截图 | 取数自动化，口径统一 |
| S1 可视化 | correlation 与工程变更前后对比有据 | 掉良率小时级发现 |
| S2 统计能力 | 工艺窗口数据化，DOE 前置筛选 | 拦截前移，逃逸分析分钟级 |
| S3 预测与优化 | 新品冷启动加速，实验次数下降 | 复判量降、停机降、产出升 |
| S4 闭环智能 | NPI 周期缩短，知识可复用可度量 | 成本与品质双改善，经验资产化 |

## 风险与前置条件

| 风险/前置 | 概率/影响 | 对策 |
|---|---|---|
| SECS/GEM 接口需厂商开通，周期不可控 | 高/高 | M0 盘点即启动商务流程；文件落地（STDF/CSV）兜底，绝不因接口阻塞整体进度 |
| 客户 IP 约束建模数据可用性 | 中/高 | 分级内建于存储路径；跨客户建模只在脱敏特征层进行 |
| 模型试点变"演示工程"，无人接手 | 中/高 | 每个模型绑定上线/下线判据与运维 Owner；未达判据即下线，不硬撑 |
| 统计限值误杀良品引发产线抵触 | 中/中 | S2 先并行跑线（只报警不拦截），误报基线达标后再切换拦截模式，切换需 QE 签字 |
| 工具蔓延过早引入分布式 | 中/中 | 触发阈值同 PART 00 ADR-3（常驻服务 >10、持续 >5×10⁴ msg/s 再评） |
